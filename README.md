# DAGs_in_ecology
This repository contains scripts to support the systematic review of DAG use in ecology and supplementary figures and simulations for Dudney, Gantois, and Simler-Williamson


- BES and ESA publication tracking.R includes code for compiling the number of publications per year in British Ecological Society and Ecological Society of America journals via CrossRef
- ADD Figure 1 code
- Simulations to support concepts in main text from Barrier 1, Myth 5, and Myth 6
